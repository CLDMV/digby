# @cldmv/digby

Digby is a DNS server built on [`@cldmv/rummage`](https://github.com/CLDMV/rummage#readme).

The project is in active pre-release development on the [`dev`](https://github.com/CLDMV/digby/tree/dev) branch. `master` carries only the v4 CI wiring until the first release.
